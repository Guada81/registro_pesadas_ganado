# Registro de Pesadas
Aplicación web para el registro y control de pesadas de ganado.

## 🛠️ Tecnologías Utilizadas
* **Backend:** Python / Django
* **Base de Datos:** SQLite
* **Frontend:** HTML5, CSS3, Bootstrap
* **Entorno de desarrollo:** Visual Studio Code

## 📦 Características Principales
* Gestión de usuarios: registro y login de usuarios, autenticación segura, diferenciación de roles (administrador, operario, lector), configuraciones personalizables.
* Registro de datos de pesada: fecha y hora, peso total (con unidad configurable: kg/lb), identificador de animal.
* Generación de informes: visualización en la app (filtrable por fecha, animal, usuario).
